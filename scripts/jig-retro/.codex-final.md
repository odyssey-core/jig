    75	
    76	This is a tiny hand-parseable YAML subset, **NOT arbitrary YAML**. Stay inside it

   189	## Gotchas
   190	
   191	- **"Verify the API at build" is where bugs hide.** Pin exact external endpoint ids,
   192	  request/response shapes, and call signatures in the plan (pattern 15). A plausible guess passes
   193	  mocked tests and breaks against the real API.
   194	- **Don't refactor working/live code under a test-only guard for a tangential feature** (pattern
   195	  14). Build new alongside; migrate later. Name the live files UNCHANGED in the plan.
   196	- **A loop with no machine-checkable evaluator converges on nonsense.** Define the evaluator
   197	  before the loop; bound every loop with a hard literal maxIters + a stop condition, and run the
   198	  first iteration attended (pattern 17). An unbound loop is a token runaway.
   199	- **Whole-project typecheck during a parallel impl wave fails on sibling not-yet-built modules**
   200	  (pattern 19). Per-module tests in the wave; full typecheck once after convergence.
   201	- **Codex rabbit-holes into `node_modules` and `| tail` buffers its output.** Scope reviews to
   202	  named files ("do NOT read node_modules, be FAST") and stream to a file.
   203	- **Subagent shells don't auto-load version managers** — every node/npx/tsx command in a subagent
   204	  prompt needs the loader preamble, or it fails with "command not found".
   205	- **Tests must be hermetic** (pattern 20) — a real `.env`/secret file or the network can silently
   206	  break a "no-key" test. Inject deps, add skip-guards, use temp dirs.
   207	- **The scorecard is a conversation, not a grade.** Not every pattern applies to every plan; mark
   208	  N/A deliberately rather than forcing all of them.
